THEFACECHOPPER – WEBOLDAL

A weboldal a megadott közösségi profilokkal, PC specifikációkkal és a feltöltött TheFaceChopper képpel készült.

FONTOS:
Az index.html és a chopper.jpg ugyanabban a mappában legyenek, mert az oldal a képet innen tölti be.

ELŐNÉZET:
Nyisd meg az index.html fájlt böngészőben.

INGYENES PUBLIKÁLÁS GITHUB PAGES-SZEL:
1. Hozz létre egy ingyenes GitHub-fiókot.
2. Készíts egy Public repository-t.
3. Töltsd fel az index.html és chopper.jpg fájlokat.
4. Repository Settings > Pages.
5. Build and deployment: Deploy from a branch.
6. Branch: main, Folder: /(root), majd Save.
7. A GitHub megadja a publikus webcímet.
